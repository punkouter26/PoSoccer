# Top 10 Free Unity Asset Store Picks for PoSoccer

Asset Store packages cannot be downloaded headlessly — they attach to your Unity account.
For each: open the link → **Add to My Assets** → in Unity: **Window → Package Manager → My Assets → Import**.

Per project policy these are **optional polish only** — nothing in the project depends on any of them.

1. **DOTween (HOTween v2)** — tweening for juice: kick punch-scales, UI slide-ins, camera shake on goals — https://assetstore.unity.com/packages/tools/animation/dotween-hotween-v2-27676
2. **Cartoon FX Remaster Free** — 50 stylized particle prefabs (2D/URP-friendly) for goal celebrations, ball impacts, wall bounces — https://assetstore.unity.com/packages/vfx/particles/cartoon-fx-remaster-free-109565
3. **FREE Casual Game SFX Pack (Dustyroom)** — kicks, bounces, scores, UI clicks for a lightweight mobile game — https://assetstore.unity.com/packages/audio/sound-fx/free-casual-game-sfx-pack-54116
4. **Free Crowd Cheering Sounds (Gregor Quendel)** — stadium crowd loops and goal-reaction roars — https://assetstore.unity.com/packages/audio/sound-fx/free-crowd-cheering-sounds-225494
5. **Fun Hyper Casual UI Pack – FREE** — bright UI sprites sized for mobile portrait 9:16 — https://assetstore.unity.com/packages/2d/gui/icons/fun-hyper-casual-ui-pack-free-302632
6. **Free Casual GUI (Sky Den Games)** — full casual GUI kit for menus, score popups, match HUD — https://assetstore.unity.com/packages/2d/gui/free-casual-gui-332804
7. **Camera Shake FX (LeastSquares)** — drop-in camera shake for goal impacts and tackles — https://assetstore.unity.com/packages/tools/particles-effects/camera-shake-fx-146554
8. **Free Pixel Font – Thaleah** — bold display font for scoreboards, timers, "GOAL!" banners — https://assetstore.unity.com/packages/2d/fonts/free-pixel-font-thaleah-140059
9. **Free Sound Effects Pack (Olivier Girardot)** — whooshes, impacts, stingers; win/lose jingles — https://assetstore.unity.com/packages/audio/sound-fx/free-sound-effects-pack-155776
10. **Free Casual Buttons Pack (traint)** — extra casual button sprites (pause, restart, settings) — https://assetstore.unity.com/packages/2d/gui/free-casual-buttons-pack-307406
